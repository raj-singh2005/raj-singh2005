1. Niyukti.io — Recruitment & Apprenticeship Platform Backend

TypeScript · Express.js 5 · PostgreSQL · Prisma ORM · Redis · BullMQ

A backend foundation for a recruitment and apprenticeship platform, with an emphasis on structured database design, reusable components, authentication, and asynchronous processing.

Key engineering work

- Designed a relational PostgreSQL schema using Prisma, including entity relationships, constraints, and database migrations.
- Worked on reusable authentication utilities involving JWT access and refresh tokens, password hashing, and cookie handling.
- Configured Redis-backed background email processing using BullMQ queues and worker processes.
- Integrated Nodemailer, SMTP, and EJS email templates for email delivery.
- Configured automated testing with Vitest, mocking utilities, and coverage reporting.
- Added Swagger/OpenAPI documentation, Winston logging, health checks, and graceful-shutdown handling.

Repository: "Niyukti.io EXP Backend" (https://github.com/raj-singh2005/Niyukti.io-EXP-Backend)
